# Cómo subir esta invitación a GitHub

1. Crea un repositorio nuevo llamado:

```text
reunion-familiar-perez-alcantara
```

2. Descomprime el ZIP.
3. Sube el contenido de la carpeta `reunion-familiar-perez-alcantara` a la raíz del repositorio.
4. Verifica que `index.html` quede directamente en la raíz.
5. Entra a:

```text
Settings → Pages
```

6. Configura:

```text
Source: Deploy from a branch
Branch: main
Folder: /(root)
```

7. Guarda y espera a que Actions termine el despliegue.

URL esperada:

```text
https://savetheclick.online/reunion-familiar-perez-alcantara/
```

No agregues `savetheclick.online` como custom domain en este repositorio. El dominio se configura solo en `ariadnacerisier-ai.github.io`.
