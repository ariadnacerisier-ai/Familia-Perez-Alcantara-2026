# Cómo subir esta invitación a GitHub

1. Crea un repositorio nuevo llamado:

```text
loteria-perez-alcantara
```

2. Descomprime el ZIP.
3. Sube el contenido de la carpeta `loteria-perez-alcantara` a la raíz del repositorio.
4. Verifica que `index.html` quede directamente en la raíz.
5. Ve a:

```text
Settings → Pages
```

6. Configura:

```text
Source: Deploy from a branch
Branch: main
Folder: /(root)
```

7. Guarda y espera a que termine el despliegue.

La URL esperada será:

```text
https://savetheclick.online/loteria-perez-alcantara/
```

No configures `savetheclick.online` como custom domain en este repositorio. Ese dominio debe permanecer únicamente en `ariadnacerisier-ai.github.io`.
